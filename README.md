## 🌐 Bogagga Website-ka (6 Pages)

1. **Home (`index.html`):**
   - Qeybta soo dhaweynta (Hero section oo leh sawir iyo CTA buttons).
   - Hordhac ku saabsan Arkaan AI Center.
   - Maxaad noo dooranaysaa (Why Choose Us - Cutting-Edge Labs, Industry Projects, Expert Mentors).
   - Mashaariicda iyo koorsooyinka caanka ah.

2. **About Us (`about.html`):**
   - Taariikhda Arkaan AI Center (Our Story).
   - Yaan nahay (Who We Are).
   - Hadafka & Aragtida (Mission & Vision).
   - Ujeeddooyinka (Goals & Objectives).

3. **Programs & Courses (`programs.html`):**
   - AI Fundamentals
   - Artificial Intelligence
   - Machine Learning
   - Data Analytics
   - Web Development
   - Other Technologies

4. **Projects & Activities (`projects.html`):**
   - Autonomous Drone Navigation (Reinforcement Learning)
   - AI Customer Support Chatbot (NLP)
   - Real-time Data Analytics Dashboard (IoT & WebSockets)
   - AI-Controlled Robotic Arm (Computer Vision)

5. **Contact Us (`contact.html`):**
   - Macluumaadka xiriirka (Email, Telefoon, Goobta).
   - Foomka fariin-dirista (Contact Form) oo leh simulation feedback.

6. **Registration (`register.html`):**
   - Foomka diiwaangelinta koorsooyinka.
   - Xaqiijinta xogta (JavaScript Client-Side Form Validation) ee Magaca, Email-ka, Telefoonka, iyo Koorso doorashada.

## 🛠️ Farsamooyinka la Adeegsaday (Technologies Used)

- **HTML5:** Qaab-dhismeedka bogagga (Semantic tags: `header`, `nav`, `section`, `article`, `footer`, `form`).
- **CSS3:** Naqshad casri ah oo adeegsanaysa CSS Variables, Flexbox, CSS Grid, iyo Media Queries (`@media (max-width: 768px)`).
- **JavaScript (ES6):**
  - Navigation menu toggle ee taleefannada gacanta (Mobile menu).
  - Xaqiijinta foomamka (Form validation & error/success messaging).
  - Smooth scrolling.
- **Git & GitHub:** Maareynta code-ka, commits nidaamsan, iyo GitHub Pages hosting.
